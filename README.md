# Password Strength Tester (Maturitní projekt)

Jednoduchá a bezpečná webová aplikace pro analýzu síly hesel založená na výpočtu informační entropie.

## Klíčové vlastnosti
- **Client-side processing**: Veškeré výpočty probíhají v prohlížeči (JavaScript). Hesla se nikam neodesílají.
- **Analýza entropie**: Výpočet teoretické síly hesla v bitech.
- **Odhad času**: Simulace útoku hrubou silou (Brute-force) při rychlosti 10^9 pokusů/s.
- **Responzivní design**: Funguje na PC i mobilních zařízeních.

## Technologie
- HTML5, CSS3, JavaScript (Vanilla JS)
- Regulární výrazy (RegExp) pro detekci znakových sad

## Instalace a spuštění
1. Stáhněte soubor `index.html`.
2. Otevřete jej v libovolném moderním webovém prohlížeči.
